## 📖 About

PujaConnect is a full-stack web platform that connects users with verified pandits for Hindu rituals and ceremonies.

Users can browse rituals, explore verified pandits, make bookings, and manage them through a premium dashboard. Pandits receive bookings, manage availability, and track earnings, while administrators oversee the complete platform.

An integrated AI Guru helps users understand rituals and choose the right puja.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/pujaconnect.git
```

Move into the project

```bash
cd pujaconnect
```

Install dependencies

```bash
bun install
```

or

```bash
npm install
```

Run the development server

```bash
bun dev
```

or

```bash
npm run dev
```

---

# 🔐 Environment Variables

Create a `.env` file in the project root.

```
VITE_FIREBASE_API_KEY=

VITE_FIREBASE_AUTH_DOMAIN=

VITE_FIREBASE_PROJECT_ID=

VITE_FIREBASE_STORAGE_BUCKET=

VITE_FIREBASE_MESSAGING_SENDER_ID=

VITE_FIREBASE_APP_ID=
```
